📂 4.1 索引管理
🗣️ 大白话：让你的每一页都被谷歌收录，而不是石沉大海。
XML站点地图 (Sitemap) ✅ 基础必做
  • 作用：告诉谷歌你的网站有哪些页面需要被收录。
  • 生成方式：使用 RankMath 或 Seopress 插件自动生成。
  • 提交路径：Google Search Console → 索引 → Sitemap → 粘贴 sitemap 地址 → 提交。
  • 验证方法：提交后查看“状态”列，显示“成功”即生效。
HTML站点地图 (用户可见) ✅ 建议做
  • 作用：帮助用户快速找到网站上的所有页面，提升用户体验。
  • 生成方式：Seopress 开启 HTML Sitemap 功能 → 复制短代码 → 新建页面“Sitemap” → 粘贴短代码 → 发布。
  • 放置位置：通常在页脚 (Footer) 区域放置入口链接。
Robots.txt 抓取协议 ✅ 基础必做
  • 作用：告诉谷歌爬虫哪些页面可以抓取、哪些不可以。
  • 常见错误：误写 Disallow: / 会直接屏蔽全站，务必检查。
  • 检查方法：访问 你的域名/robots.txt 查看内容是否正常。
Canonical 标签规范化 ✅ 基础必做
  • 作用：当多个 URL 展示相同内容时，告诉谷歌哪个是“首选版本”。
  • 使用场景：产品变体页面（例如带有 ?color=purple 参数的紫牙贴变体链接）、分页、筛选链接等。
  • 实现方式：使用 Seopress 的 Canonical URL 字段指定主版本 URL。
Noindex 标签管理 ⚠️ 注意检查
  • 作用：告诉谷歌“不要索引这个页面”。
  • 使用场景：客户付款后的感谢页、内部测试页、重复内容页等。
  • 常见问题：误将重要页面添加了 Noindex 标签，导致彻底不被收录。
  • 检查方法：Google Search Console → 覆盖率报告 → 查看“排除”原因。
重复内容检测与处理 ⚠️ 注意检查
  • 检测工具：Siteliner（免费版可检测单站点）。
  • 处理方案：若重复不可避免（如高度相似的产品线），使用 Canonical 指向主版本；或合并同类项成单页，使用变体参数供客户选择，避免被谷歌视为低质量内容。
📂 4.2 抓取优化
🗣️ 大白话：谷歌蜘蛛来了，你得给它铺好路，别让它迷路。
去除抓取障碍 ✅ 基础必做
  • 展开内容：检查 robots.txt 是否误屏蔽了重要页面。
  • 方法：在 GSC 的 URL 检测工具中查看“是否允许抓取”。若显示“被阻止”，立即去除误屏蔽规则。
修复孤岛页面 (Orphan Pages) ⚠️ 进阶优化
  • 定义：没有任何内部链接指向的页面（谷歌找不到它）。
  • 检测与修复：用 Ahrefs 查看 Links 报告修复。优先在高权重文章或详情页中加内链主动指向它。
内部 nofollow 链接排查 ⚠️ 进阶优化
  • 展开内容：nofollow 标签会阻止权重传递。若需要谷歌抓取并排名该页面，必须删除指向它的内链 nofollow 标签。
📂 4.3 网站健康管理
🗣️ 大白话：网站底子好，谷歌才愿意多来串门，用户才愿意多停留。
301 / 302 重定向 ✅ 基础必做
  • 301 永久跳转：删除页面、修改固定链接、网站重建时使用（如老款链接权重无缝转移给新款）。
  • 302 临时跳转：A/B 测试或临时活动页使用。
  • 工具：WordPress 插件“Redirection”一键设置。
404 页面自定义 ✅ 建议做
  • 展开内容：访问不存在页面时展示友好提示。使用 Elementor 主题构建器添加模板，设计引导内容（如热门产品推荐、返回首页）。
  • 监控：在 GSC 覆盖率报告中监控并及时修复死链。
Core Web Vitals (核心网页指标) ⚠️ 持续优化
  • INP：评估交互响应速度。
  • LCP：主内容加载速度，目标 < 2.5秒。
  • CLS：视觉排版稳定性，目标 < 0.1。
  • 优化方向：强制图片转 WebP、启用 CDN、减少第三方脚本、设置图片固定宽高比防抖动。
移动端完美适配 ✅ 基础必做
  • 展开内容：使用 Elementor 响应式设置分别检查。文字需 16px 以上，按钮间距 44px 以上。严防弹窗遮挡或表格超宽导致页面错位。
