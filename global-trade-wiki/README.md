# GLOBAL TRADE WIKI | 全球贸易合规与履约知识库

## 项目简介
这是一个基于 `Wikipedia × Notion` 极简阅读风格构建的个人百科型知识库。
旨在为跨境贸易/电商从业者提供全面、可查、易读的合规与履约决策支撑体系。

## 五大核心维度
1. **市场准入与合规** (企业资质、产品强制认证、ESG、环保包装)
2. **物流清关与履约** (Incoterms 2020、HS Code 风控、提单物权、退税单证)
3. **资金结算与财税** (B2B 结算、资金防冻与 AML 举证、属地化税务筹划)
4. **知识产权与维权** (亚马逊内部防卫生态、美国 TRO 禁令应对、数字前端合规)
5. **平台治理与商业契约** (信保仲裁规则、FTC 广告虚假宣传审查、地缘出口管制)

## 辅助入口 (Quick Links)
