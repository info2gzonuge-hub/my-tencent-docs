代工厂准入审查清单 (SOP)

防范小作坊与二道贩子，确保供应链源头合法合规、产能真实可靠。

  • 资质三证核验：核查营业执照、实际生产许可证及环评批复。
  • 验厂标准匹配：确认 ISO9001 质量管理体系或 BSCI 验厂报告。
  • 知识产权隔离：下单前签署严格的 NNN（保密、不使用）协议。
  • 产能与品控抽检：评估产线工人数、机器设备及出货前 AQL 抽检。
📦

大宗出货防冻卡与资金风控

从 PI 报价到结汇水单，四单合一防洗钱风控与离岸账户冻结应对。

  • 四单合一核对：确保形式发票 (PI)、装箱单、提单信息一致。
  • 离岸账户合规：排查高风险款项，防范地下钱庄导致账户被冻。
  • 结汇水单留存：妥善保存报关单与银行结汇凭证以备查验。
🚨

TRO 资金救援 21 天倒计时

遭遇流氓律所起诉后的应急止损、下架隔离与和解谈判步调指南。

  • 第 1-3 天（应急止损）：确认冻结通知、排查侵权链接并下架。
  • 第 4-10 天（应诉评估）：选择直接和解、放弃店铺或聘请律师出庭。
  • 第 11-21 天（谈判执行）：提交划扣比例谈判并申请解除冻结。

独立站合规上线排雷表

涵盖 FTC 欺诈自查、GDPR 弹窗、ADA 无障碍代码及支付接口验证。

  • FTC 自动扣费合规：检查结账页是否存在隐形订阅陷阱。
  • GDPR 隐私合规：部署欧盟 Cookie 同意弹窗及隐私数据通道。
  • ADA 无障碍合规：确保网站支持屏幕阅读器与键盘导航。
  • 支付通道风控：配置 Stripe 欺诈过滤器与 3DS 验证。
✈️

特货清关与单证检查单

带电、带粉末、带膏体产品的 MSDS 审核与海关 HS Code 预归类防坑。

  • MSDS 安全数据表：核查电池或膏体成分符合国际运输标准。
  • HS Code 归类确认：向报关行确认税号，避免海关查扣。
  • 目的港准入单证：提前确认特种进口许可与药监局合规。
⚖️

侵权申诉与反制清单

遭遇恶意搞后的 UPNEP 专利中立评估举证及 DMCA 反通知提交流程。

  • 专利非侵权比对：逐一比对权利要求，制作技术差异表。
  • UPNEP 中立评估：在亚马逊专利评估期内提交有力证据。
  • DMCA 反通知：针对版权恶意投诉按规定提交不侵权声明。
