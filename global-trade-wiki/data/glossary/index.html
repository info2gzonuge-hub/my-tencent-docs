Global Trade Glossary & Abbreviations

A-E
AWB / BEC / CI / DDP...
涵盖空运单、钓鱼邮件、商业发票、完税交货等基础缩写。
F-J
FOB / FTC / FTO / HS...
涵盖离岸价、联邦贸易委员会、专利防侵权排查、海关编码等。
K-O
L/C / MSDS / NNN / OFAC...
涵盖信用证、安全说明书、保密不规避协议、美国制裁名单等。
P-T
PI / POD / REACH / TRO...
涵盖形式发票、签收证明、欧盟化学指令、联邦临时禁令等。
U-Z
UDRP / UPNEP / VAT / WEEE...
涵盖域名仲裁、专利中立评估、增值税、电子废弃物指令等。
